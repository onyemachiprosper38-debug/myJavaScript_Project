## 📦 Projects

### 1. **Mobile Calculator** 🧮
The main project featuring a fully functional mobile calculator with a intuitive interface.
- **Features:**
  - Basic arithmetic operations (+, -, *, /)
  - Clear (C) and Delete (DEL) functions
  - Real-time calculation with eval-based computation
  - Error handling for invalid expressions
  - Responsive design optimized for mobile devices

**Files:** `index.html`, `script.js`, `style.css`

### 2. **Product List with Cart** 🛒
An interactive e-commerce-style dessert store featuring dynamic product management and shopping cart functionality.
- **Features:**
  - Dynamic product listing with images
  - Add to cart functionality
  - Product details (category, name, price)
  - Responsive grid layout
  - Professional styling with CSS

**Directory:** `product-list-with-cart-main/`

### 3. **My Website Project** 💼
A professional website showcasing digital transformation and business solutions.
- **Features:**
  - Modern, clean design
  - Custom CSS styling
  - Professional branding messaging
  - Fully responsive layout

**Directory:** `MyWebsite-Project/`

### 4. **Product Data Hub** 📊
A data-driven application for managing and displaying product information.
- **Features:**
  - JSON data handling
  - Dynamic content rendering
  - Structured data management

**Directory:** `Product-Data-Hub/`

### 5. **JS Task 1** ✅
JavaScript fundamentals project covering core ES6+ concepts.

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of HTML, CSS, and JavaScript

### Installation

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd myJavaScript_Project
   ```

2. **Open any project in your browser:**
   ```bash
   # For the calculator (root project)
   open index.html
   
   # Or for other projects
   open product-list-with-cart-main/index.html
   open MyWebsite-Project/index.html
   ```

### Running Projects Locally

Most projects run directly in the browser without any build process:
1. Navigate to the project folder
2. Open `index.html` in your preferred web browser
3. Interact with the application

**Note:** No external dependencies required - pure vanilla JavaScript!
